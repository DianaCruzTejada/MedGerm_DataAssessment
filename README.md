# Modeling seed germination data to meet biodiversity conservation needs in the Mediterranean

This repository includes datasets, thermal germination modelling outputs, and scripts used to evaluate germination data availability and quality for characteristic Mediterranean plant species, and to estimate species-level thermal risk categories relevant for conservation and restoration planning under climate change.

The analyses integrate germination data compiled from published sources with species traits, habitat information, and thermal niche modelling to identify taxonomic, ecological, and functional patterns in data availability and climate-related germination risk.

## Contents

The following materials are available in this repository:

- `data`: input datasets used for analyses, including species traits, habitat classifications, germination datasets, and thermal modelling inputs.
- `results`: outputs generated from thermal germination modelling, statistical analyses, figure generation, and Supporting Information elements associated with the manuscript.
- `scr`: R scripts used to perform analyses.

## Main analyses

The repository includes scripts and outputs associated with:

- assessment of germination data availability across Mediterranean species,
- evaluation of data quality for thermal germination modelling,
- estimation of thermal germination niche parameters.
